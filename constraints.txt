# Exact-version constraints for reproducible installs.
#
# This pins every runtime dependency (direct + transitive) to the exact
# version verified against the test suite, so `pip install` cannot pull in
# an untested newer release — including of a transitive dependency not
# listed in requirements.txt. Regenerate after intentionally upgrading:
#
#   pip install -r requirements.txt --upgrade
#   pip freeze | grep -v -- '^-e' > constraints.txt
#   # then re-run: pytest -v  (and, ideally, a real router install check)
#
# Apply with:
#   pip install -r requirements.txt -c constraints.txt
# or, for the dev environment:
#   pip install -r requirements-dev.txt -c constraints.txt
#
# No cryptographic hashes are pinned here (`--require-hashes`) because the
# router's CPU architecture may need different wheels/sdists than this
# development machine resolves; hash pinning would have to be generated
# separately per target platform. See AGENTS.md's dependency notes.
